# Steganography Tool

A Windows desktop application for hiding encrypted text within images using steganography.

The tool uses the [least significant bit (LSB) steganography](https://ctf101.org/forensics/what-is-stegonagraphy/) to hide information within image pixels.

## Features

- **Image Loading**: Load PNG and JPEG images as carriers for hidden messages
- **Text Embedding**: Hide encrypted text within images
- **Text Extraction**: Retrieve hidden messages from steganographic images
- **Encryption**: All embedded text is automatically encrypted using AES
- **Key Management**: Option to regenerate encryption keys
